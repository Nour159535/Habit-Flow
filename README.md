# Habit Flow

A responsive habit-tracking dashboard built with React.js as part of my journey in learning and practicing frontend development.

## Live Demo

[View Habit Flow](https://habit-flow-project.vercel.app/)

## About The Project

Habit Flow is a personal project designed to help users organize their daily habits, track their progress, and build consistent routines through a clean and interactive dashboard.

The project was developed as a practical way to strengthen my React.js skills and apply frontend development concepts.

## Features

- Add, edit, and delete habits.
- Track habit completion and progress.
- Search habits by name.
- Filter habits by status.
- Save habit data using Local Storage.
- Navigate between pages using React Router.
- Responsive user interface.

## Technologies Used

- React.js
- JavaScript (ES6+)
- CSS3
- React Router
- Day.js
- Local Storage
- Vite

## Getting Started

To run the project locally:

1. Clone the repository:

   git clone (https://github.com/Nour159535/Habit-Flow)

2. Navigate to the project directory:

   cd habit-flow

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev
